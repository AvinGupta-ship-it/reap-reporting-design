# Synthetic data

Every file in this directory is **synthetic**: it is generated by
`reapschema.pipeline` from the configuration and seed recorded in the accompanying
`.meta.json` sidecar. No file contains REAP application data.

- `synthetic_applicants_<config>.parquet` — one row per synthetic applicant: ground
  truth, injected error label, estimator values and rule scores for the evidence as
  reported (`r_*`) and error-free (`c_*`).
- `synthetic_evidence_packages_<config>.json` — a few complete evidence packages as
  instances of the schema in `src/reapschema/schema/reap_evidence.yaml`.
